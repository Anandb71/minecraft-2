# Controls

Left click captures the mouse. Start on a pad does the same. Esc releases,
then quits.

## Keyboard and mouse

| Input | Action |
|---|---|
| Left click | Capture mouse; then hold to break / carve |
| Right click | Place the held block / deposit; use a crafting table or furnace |
| Middle click (held) | Preview the targeted block |
| I | Inventory and recipes |
| Right click with a bucket | Fill it from water; pour a full one where you aim |
| Right click with flint and steel | Set what you aim at alight |
| W A S D | Move |
| Space | Jump (fly: up) |
| Ctrl or C | Crouch (fly: down) |
| Shift | Sprint |
| F | Toggle flying |
| F5 | First / third person |
| Tab | Block mode / carve mode |
| E | Light the targeted TNT (4 s fuse) |
| 1–9, mouse wheel | Hotbar (carve mode: wheel changes radius) |
| F3 | Profiler HUD |
| F4 | Debug view: shaded, LOD hits, march heatmap, unlit |
| F6 | Cycle graphics quality |
| T | Pause or resume time |
| [ ] | One hour back or forward |
| V | Toggle vsync |
| P | Photo mode |
| F2 | Screenshot |
| Esc | Release mouse, then quit |

## Gamepad

Xbox layout. PlayStation and Switch pads use the same slots: south jump,
east crouch, west TNT, north fly. Push the left stick all the way to sprint.

| Control | Action |
|---|---|
| Left stick | Move |
| Right stick | Look |
| A / south | Jump (fly: up) |
| B / east | Crouch (fly: down) |
| X / west | Light TNT |
| Y / north | Toggle flying |
| RT | Break / carve |
| LT | Place / deposit |
| LB / RB | Hotbar (carve: brush size) |
| L3 | Sprint |
| R3 | First / third person |
| D-pad up | Block / carve mode |
| D-pad down (held) | Preview the targeted block |
| Start | Capture or release play |
| Back / Select | Photo mode |

## Photo mode

Time stops. The camera flies free. Enter renders 96 frames at Super Ultra
Crazy Duper Realistic into `captures/photo_<time>.png`.

| Keyboard | Pad | Action |
|---|---|---|
| W A S D, Space, Ctrl | Left stick, A / B | Fly |
| Mouse | Right stick | Look |
| Wheel | LT / RT | Focal length, 12–400 mm |
| Q / E | D-pad up / down | Focus |
| Z / X | LB / RB | Aperture |
| , / . | D-pad left / right | Exposure |
| G | Y | Depth of field |
| Enter or F2 | Start or X | Capture |
| P | Back / Select | Leave |
| | L3 | Faster fly |

## Survival

The game starts in survival with empty hands. Hold left click to break a
block: logs and dirt give way to bare hands, rock needs a pickaxe, iron ore a
stone one, and better tools break things faster until they wear out. Press I
for the inventory: drag stacks between the pack and the hotbar (right click
splits, shift click moves) and click a recipe to make it. Logs become planks,
planks sticks and a crafting table; at the table come tools, a furnace, stone
bricks, windows, lanterns, concrete and TNT (gunpowder is coal and flint from
gravel); the furnace, fed coal or wood, makes glass, iron and steel ingots,
charcoal and bricks. `--creative` gives an endless hotbar and a catalogue of
every item instead.
